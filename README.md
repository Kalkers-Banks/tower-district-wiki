# Tower District Wiki

The Tower District Wiki is a community wiki for documenting Tower District, including its towers, citadels, difficulties, and districts.

## About

The wiki aims to provide an organized reference for Tower District content, with information about individual towers and their classifications.

## Hosting

The wiki is intended to run locally using [MediaWiki](https://www.mediawiki.org/wiki/MediaWiki), with the goal of keeping setup simple and making the wiki easy to maintain.

# Requirements

- Debian-based Linux environment
- MediaWiki
- PHP and the required extensions
- A supported database backend

# Local development

Installation and setup instructions will be documented here once the MediaWiki environment is configured.

# Contributing

Contributions should follow the established Tower District tower lists and classifications. Please verify information before adding or editing entries.
